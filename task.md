## 1. Задача

Реализуй API, которое позволяет создать бронь, получить список броней, получить бронь по id и отменить её.

### Эндпоинты

| Метод  | Путь            | Описание                                                                                          |
| ------ | --------------- | ------------------------------------------------------------------------------------------------- |
| POST   | `/bookings`     | Создать бронь. Возвращает 201 и созданную бронь.                                                  |
| GET    | `/bookings`     | Список броней. Необязательный фильтр по дате: `?date=2026-12-15`.                                  |
| GET    | `/bookings/{id}`| Получить бронь по id. 404, если не найдена.                                                       |
| DELETE | `/bookings/{id}`| Отменить бронь: статус меняется на `cancelled`, запись не удаляется. Возвращает 200 и бронь.      |

### Данные брони

| Поле           | Тип    | Правило                                                     |
| -------------- | ------ | ----------------------------------------------------------- |
| `name`         | `str`  | Имя гостя, от 2 до 50 символов.                             |
| `phone`        | `str`  | Номер в формате `+7XXXXXXXXXX` (ровно 10 цифр после `+7`).  |
| `booking_date` | `date` | Не в прошлом и не дальше чем через 30 дней.                 |
| `booking_time` | `time` | Только целые часы с 12:00 до 22:00.                         |
| `guests`       | `int`  | От 1 до 10.                                                 |

### Главное правило

На одну дату и время может быть только одна **активная** бронь. Повторная бронь на занятый слот получает **409**. Отменённая бронь слот не занимает.

## 2. Стек и требования

### Обязательно

- Python 3.11+, FastAPI, Pydantic v2
- Хранение — в памяти (`dict`) или SQLite, на твой выбор. На оценку не влияет
- Разделение хотя бы на роуты, сервис и схемы

### Пример схем

```python
from datetime import date, time
from typing import Literal
from pydantic import BaseModel, Field


class BookingCreate(BaseModel):
    name: str = Field(min_length=2, max_length=50)
    phone: str = Field(pattern=r'^\+7\d{10}$')
    booking_date: date
    booking_time: time
    guests: int = Field(ge=1, le=10)


class BookingOut(BaseModel):
    id: int
    name: str
    phone: str
    booking_date: date
    booking_time: time
    guests: int
    status: Literal['active', 'cancelled']
```

### Ошибки

| Ситуация           | Код | Ответ                                              |
| ------------------ | --- | -------------------------------------------------- |
| Бронь создана      | 201 | Созданная бронь со `status=active`                 |
| Невалидные данные  | 422 | Стандартный ответ валидации FastAPI                |
| Бронь не найдена   | 404 | `{"detail": "Booking not found"}`                  |
| Слот уже занят     | 409 | `{"detail": "Slot is already booked"}`             |
| Бронь отменена     | 200 | Бронь со `status=cancelled`                        |

Swagger на `/docs` FastAPI создаёт сам, настраивать ничего не нужно.
